Step-by-step instructions for every screen, with pictures, for owners, front desk, nurses, clinicians, lab, pharmacy and cashiers. Start with the chapter for your job, or use the search on the left.

01

Before you start

For: owner, administrator, Pentarch installer

MediCore runs on one main computer at the facility. Every other computer, tablet and phone opens it in a web browser over the facility Wi-Fi. It does not need the internet to work, so power and the router are what keep it running.

What you need

ItemMinimumWhy
Main computerWindows 10 or 11, 4 GB RAM (8 GB better), 20 GB free diskHolds the system and all the data
Node.js 22 LTSVersion 22.13 or newer, from nodejs.orgThe engine MediCore runs on. Main computer only
Wi-Fi routerAny home or office routerConnects the other devices to the main computer
Other devicesAny phone, tablet or PC with Chrome or EdgeNothing to install on them
BackupA flash disk or external driveWeekly backup file from Settings
Power backupA UPS for the main computer and routerKeeps the system up during short outages

Words used in this manual

  • Facility: the client business, for example SPENSA Pharmacy. It has an owner and staff.
  • Branch: one location of that facility. A facility can have many branches, and each can be a pharmacy, a clinic or a hospital.
  • Role: what a staff member does (cashier, nurse…). The role decides which menus they see.
  • Sample data: practice patients, sales and stock for demos and training. You remove it before going live (Chapter 21).
  • Automatic billing: charges are added to the patient's bill as services happen. With manual billing, the cashier adds them.
02

Install, start, update

For: owner, Pentarch installer · about 15 minutes the first time

Install on the main computer

  1. Go to nodejs.org, download the LTS version for Windows and install it with the default options.
  2. Get MediCore: on GitHub, open the pentarch-medicore repository, click Code → Download ZIP.
  3. Unzip it to a short path such as C:\MediCore. Avoid the Downloads or Desktop folders, which some cleaners empty.
  4. Double-click start-medicore.bat. If Windows shows a blue warning, click More info → Run anyway.
  5. The first run installs and builds the system. This needs internet for 3 to 5 minutes. When it finishes, the browser opens on the setup wizard (Chapter 3).
  6. If Windows Firewall asks, tick Private networks and click Allow. Without this, other devices cannot connect.
Keep the black window open

The black window titled “Pentarch MediCore” is the system running. Minimise it, but do not close it while people are working. Closing it stops MediCore for every device.

Start it every day

  1. Switch on the main computer and the router.
  2. Double-click start-medicore.bat. It opens in a few seconds and needs no internet.
  3. Other devices open the bookmarked address (next section).
Start it automatically

Press Win+R, type shell:startup and press Enter. Put a shortcut to start-medicore.bat in the folder that opens. MediCore then starts whenever the computer starts.

Connect other devices

  1. Connect the phone, tablet or PC to the same Wi-Fi as the main computer.
  2. On the main computer, open Settings → Other devices and read the address, for example http://192.168.1.20:4000. The black window shows it too.
  3. Type that address in Chrome or Edge on the other device and bookmark it. Each person signs in with their own username and PIN.

Update to a new version

  1. Close the black window to stop MediCore.
  2. Copy the data folder somewhere safe first. It holds all patients, stock and money.
  3. Download the new ZIP and unzip it over the same folder, replacing files when Windows asks. Your data folder stays.
  4. Double-click start-medicore.bat. It sees the new version number, installs it (internet for a few minutes), then starts.
  5. Check the version at the bottom of the menu, for example MediCore v2.2.0.
Still seeing the old screens?

If you unzipped to a new folder, copy your old data folder into it. If the menu shows no version number, you are still on the first demo: update as above, then press Ctrl+F5 in the browser.

The dashboard and getting around

For: everyone

After signing in you land on the dashboard: what is happening today, what needs attention, and where the money is.

Card details

Each card opens a breakdown with the list behind the number. Click a row to jump straight to that bill, visit or test.

Tips on screens

06

Patients

For: reception, nurses, clinicians

Find a patient first

Always search before registering, so one person never has two files. Search by name, MRN (file number), phone, ID or SHA number.

Register a new patient

  1. Open Patients and click Register patient.
  2. Enter first and last name, sex and date of birth. If the patient does not know the date, type the age and MediCore estimates it.
  3. Add the phone (for example 0712 345 678), ID and SHA number if available, county, allergies and next of kin.
  4. Click Register and add to queue. The patient goes straight to the triage queue.
The system stops common mistakes

It refuses a date of birth in the future, a phone number that is not Kenyan, and an ID number that is already registered. If it says the patient already exists, search for them instead.

The patient dashboard

Click a patient to see their health at a glance: health bars against normal ranges, blood pressure, sugar and weight trends, lab history, current pregnancy, allergies and every visit.

07

Queue and triage

For: reception, nurses, clinicians

The service queue shows every patient in the facility today as a ticket, grouped by stage. It refreshes on its own.

Triage levels (Kenya ETAT+)

EmergencyTreat now: airway, breathing, circulation, coma, convulsion, severe dehydration, heavy bleeding.
PrioritySeen next: very high fever, severe pain, pallor, infant under 2 months, trauma, pregnancy with danger signs.
QueueStable: seen in turn.

Triage a patient

  1. Open the patient from the queue.
  2. Tick the danger signs. The level updates.
  3. Type the main complaint and the pain score.
  4. Enter vital signs: temperature, blood pressure, pulse, breathing rate, SpO₂, weight, height, and sugar or MUAC if taken.
  5. Click Save triage. The patient moves to “Waiting clinician”.
08

Consultation, orders and prescriptions

For: clinical officers, doctors, pharmacists giving consultations

Notes and diagnosis

  1. Open the Consultation tab.
  2. Write the history and examination findings.
  3. Pick the diagnosis from the list (ICD-10 coded, used for MOH 705) and write the plan.
  4. Click Save note.

Order lab tests

In Orders & prescriptions, the test picker opens on the common tests. Switch to a department or search. A panel such as “Fever work-up” ticks a whole set in one click.

Prescribe

Pieces, not boxes

A course of 15 paracetamol tablets is dispensed as 15 tablets, and stock drops by 15 straight away. Nobody has to wait for a box to finish.

Procedures, results, imaging, referral and admission

  • Procedures (circumcision, dressing, suturing…): record consent, notes and the supplies used. Supplies come off stock and the fee goes on the bill.
  • Results: validated lab results for this visit, flagged high, low or critical.
  • Imaging: request an ultrasound or X-ray, in-house or at a partner centre. Type the report when it comes back.
  • Refer: the referral letter is filled in from the visit (vitals, diagnosis, results). Print or send it.
  • Admit (clinics and hospitals): choose ward and bed; the admission fee posts.
09

Laboratory

For: lab technicians and technologists

The workflow follows good laboratory practice: collect sample → enter result → a second person validates before the result is released to the clinician and patient.

  1. Click Collect sample when you take the sample. The time is recorded.
  2. Click Enter result. Numbers are checked against the normal range for the patient's sex; choices such as Positive/Negative are one tap.
  3. Save. The result waits in To validate.
  4. A second person checks it and clicks Validate. It is now released.
Critical values

Results beyond the critical limits are marked Critical in red and shown on the dashboard. Phone the clinician straight away and record that you did in the comment.

Tests sent to a partner lab

Order the test as “Partner lab”. It shows as Sent out. When the result comes back on paper or by email, open the test and enter it as normal, so it sits in the patient's record.

10

Pharmacy and stock

For: pharmacists, pharmaceutical technologists, cashiers (counter sale)

Dispense prescriptions

  1. Open Pharmacy & stock → Prescriptions.
  2. Check each line: medicine, dose, quantity and allergies shown at the top.
  3. Click Dispense. Stock is taken from the batch that expires first, the charge posts, and the label prints.

Counter sale (walk-in customers)

  1. Search or scan the barcode, or filter by category.
  2. Tap the product. Switch between pieces and full pack; the price changes to match.
  3. Prescription-only items (marked Rx) need a prescription reference before payment.
  4. Click Take payment, choose Cash, M-Pesa or Card, and record. Print or close the receipt.

Inventory

Click the cards at the top: Below reorder level lists what to order, Expiring lists batches to sell first or return, and Stock value breaks the money down by category.

One item: photo, batches, count

  • Stock count: for one item, use Adjust, enter what you counted and the reason. For a shelf or category, use Stock take (Chapter 12). Both are recorded in the audit trail.
  • Expired stock is never sold: it is skipped automatically and listed under Expired & disposal (Chapter 13).

Receive stock from a supplier

  1. Click Receive stock.
  2. Choose the supplier and type the invoice number.
  3. For each item: packs received (and loose pieces if any), cost per pack, batch number and expiry date.
  4. Save. Stock and stock value update immediately.
Good practice

Always enter the real batch number and expiry. That is what makes first-expiry-first-out and recalls work.

11

Billing and checkout

For: cashiers, reception, administrators

With automatic billing (the default) every consultation, test, medicine, procedure and bed-day lands on the patient's bill as it happens. The cashier only checks and takes payment. With manual billing, the cashier adds the items.

Check a patient out

  1. Open Billing & checkout and click the patient's bill.
  2. Check the lines with the patient. Add an item with the search box if something is missing.
  3. Choose who pays: cash, SHA, insurance or company.
  4. Take payment: Cash (change is shown), M-Pesa (sends a prompt to the patient's phone), Card. Split payments are fine.
  5. When the balance is zero the bill closes and the receipt is ready.

Discounts, removing lines and credit

  • Discount: needs a supervisor PIN and a reason. Both are recorded.
  • Remove a line: supervisor only, with a reason.
  • Credit: if a patient cannot pay in full, put the balance on credit. It appears under Credit / debtors and on the dashboard until settled.
Close the day

At closing, open Reports → Revenue for today and count the cash drawer against the cash total. M-Pesa should match the M-Pesa statement.

12

Counter, cash and stock control

For: owners, administrators, pharmacists, cashiers

These tools stop money and stock from quietly going missing. Every action carries a name and a time, and differences need a reason.

Shifts and cash-up

  1. At the start of the day, open Pharmacy & stock → Counter sale and click Open shift. Count the float in the drawer and type it in.
  2. Sell as normal. Cash and M-Pesa payments are linked to the open shift.
  3. At closing, open Billing & checkout → Shifts & cash-up and click Close shift. Count each note and coin. MediCore shows what should be in the drawer and the difference.
  4. If the cash is over or short by KES 1 or more, type the reason. Print the Z-report for the file.
One cashier per drawer

If two people share a drawer, nobody can be held to the count. Give each cashier their own shift.

Parking a sale

A customer has gone to fetch money and the queue is growing. Press F8 or click Park sale. The cart is saved on this counter. Serve the next customer, then click the parked sale above the cart to bring it back.

Returns and refunds

  1. At the counter, click Return and find the receipt by number, customer or phone.
  2. Enter the quantity coming back, choose the reason and whether the stock goes back on the shelf.
  3. A supervisor enters their PIN. The refund goes back to the original batch and shows on the shift and in reports.

Barcodes and labels

Scan an item's barcode at the counter or when receiving. The square 2D codes on medicine packs also carry the batch and expiry, which MediCore fills in for you. For items without a barcode, open the item and click Generate under Barcode, then print labels from the Barcode labels tab.

Purchase orders and receiving

  1. Open Purchase orders and start a new order. Use the suggestion to fill in what is below its reorder level.
  2. Send it to the supplier by WhatsApp or print it.
  3. When the delivery arrives, open the order and click Receive. Scan each pack, check batch and expiry, and save. A part delivery leaves the rest open.

Importing opening stock

When a shop starts on MediCore, its stock is often already in an Excel sheet. Open Pharmacy & stock → Inventory → Import stock and click Download a template to see the columns: name (or code), packs, loose units, batch, expiry, cost per pack and price per pack.

  1. In Excel, keep one row per batch and click File → Save As → CSV.
  2. Choose the file and click Check the list. Each row shows what it matched in the medicine list. Rows matched only by a similar name say so: check them.
  3. Rows marked not found or to fix are skipped. Tick Add items that are not in the catalogue to create them (they need a selling price).
  4. Click Add … lines to stock. Fix the skipped rows in Excel and import them again later.

To give your accountant the stock list with quantities and values, click Export on the same screen. The file opens in Excel.

Stock take

  1. Open Pharmacy & stock → Stock take. Choose a category or shelf, or the whole store, and click Create count sheet.
  2. Count what is on the shelf and type it in boxes and pieces. You can print the sheet, count on paper and type the numbers in later.
  3. Click Save counts as you go. The sheet shows short and over lines and the value of the difference at cost.
  4. An administrator checks the differences and clicks Post count. Stock changes to the counted quantities, and any loss shows as shrinkage in Profit & loss.
Count a little, often

Count one category each week rather than the whole shop once a year. A difference found early is easier to explain.

Expenses and branch transfers

Record rent, salaries, power and other costs under Billing & checkout → Expenses, so the profit report shows the true net. Cash paid out of the drawer lowers the cash expected at cash-up. Facilities with several branches move stock with Transfers: the sending branch dispatches, the receiving branch confirms, and nothing disappears in between.

The owner's daily summary

Reports → Daily summary shows the day on one screen: money collected by method, gross profit, expenses, each cashier's cash-up, top sellers, and what is out of stock or expiring. Click Send on WhatsApp to send it to the owner. Add the owner's number in Settings → Facility and it opens straight to their chat.

Profit and loss

Reports → Profit & loss uses the real cost of each batch sold, so the margin stays true when supplier prices change. It also lists the least profitable items and stock that has not sold in 90 days.

13

Money owed, prices and backups

For: owners, administrators, pharmacists, cashiers

This chapter covers the money that sits outside the till: customers who buy on account, suppliers you owe, SHA and insurance claims, and selling prices that drift when suppliers change their costs. It ends with the backup that protects all of it.

The to-do list on the dashboard

Administrators see To do today at the top of the dashboard. It lists only what needs a decision: expired stock on the shelf, items selling below cost, overdue supplier invoices, claims to submit or chase, customer debts, short stock and an overdue stock count. Clinics and hospitals also see lab results waiting validation, patients waiting over an hour and admitted patients with no observations for 8 hours. The most urgent items come first. Click an item to open the screen where you deal with it.

Customers who buy on account

  1. Open Billing & checkout → Customers and click New customer, or Edit an existing one. Set a credit limit: how much they may owe at any time.
  2. At the counter, pick the customer and click Put on … account. They can also pay part now and put the rest on account. MediCore refuses a sale that would take them over their limit.
  3. When they pay, click Statement · pay next to their name, enter the amount and method and click Record payment. The payment clears their oldest purchases first.
  4. Click Print statement to give them a dated statement with every purchase, payment and the balance.

Suppliers and what you owe them

When you receive a delivery against a purchase order, MediCore adds the supplier's invoice for you, with a due date from that supplier's credit terms. You can also add an invoice by hand with Record supplier invoice.

  1. Open Pharmacy & stock → Suppliers. The top cards show the total owed, what is overdue and what falls due in the next 7 days.
  2. Click Pay to record a payment by bank, M-Pesa or cash. Pay the oldest invoice first.
  3. Click Statement to see every invoice and payment for that supplier. Compare it with the statement the supplier sends you at month end.
  4. Use Edit to set the supplier's credit terms in days, contact person and Paybill.

Keeping prices right

Supplier costs go up. If your shelf prices do not follow, you sell at a thinner margin, and sometimes at a loss, without noticing. When a delivery comes in at a higher cost, MediCore tells you which prices to check.

  1. Open Pharmacy & stock → Prices. Set your target markup over cost (33% is a common retail figure; set your own default in Settings → Facility).
  2. The list shows items below target, and those selling below cost, with a suggested price rounded to a sensible figure.
  3. Tick the items to change and click Apply suggested prices. Each change is recorded with the old price, new price, cost and who made it.
Check after every delivery

A price review takes two minutes after receiving stock and protects the margin on everything you sell until the next delivery.

Expired and damaged stock

  1. Open Pharmacy & stock → Expired & disposal. Batches that have expired, or expire within 60 days, are listed with their value at cost.
  2. Type how many pieces are going out (or click All), choose the reason and how it will be disposed of, and enter the witness's name.
  3. The stock comes off straight away and the loss shows in Profit & loss. Click Print register for the disposal record that Pharmacy and Poisons Board inspectors ask to see.

SHA and insurance claims

Every bill paid by SHA or a private insurer becomes a claim. Open Billing & checkout → SHA & insurance claims. The cards show what is owed and how old it is.

  1. To submit: once you send the claim to the payer, click Mark submitted and enter the claim number.
  2. Submitted: when money arrives, click Record payment and enter the amount and remittance number. A part payment stays open for the balance.
  3. Rejected: record the payer's reason. Fix the problem (for example, the member was not active) and resubmit, or bill the patient.
  4. Click Export CSV to send a list to the payer or your accountant.

Backups

A backup is one file holding every branch's patients, stock, sales, staff and settings. Make one at least once a week, and keep it away from this computer, on a flash drive or Google Drive, so a stolen or broken computer does not take your records with it.

  1. Open Settings → Data & backup and click Download backup now. The file ends in .mcbak and carries the facility name and date.
  2. Copy the file to your flash drive or Google Drive.
  3. To restore, open Restore from a backup file, choose the file and type RESTORE to confirm. This replaces what is in MediCore now with the copy in the file, so only do it after a computer failure or on Pentarch's advice.
The dashboard reminds you

If no backup has been made for 7 days, administrators see a reminder on the dashboard until they make one.

14

Wards, beds and maternity

For: clinics and hospitals with admissions · nurses, midwives, clinicians

Inside an admission

Observations, medicines and discharge

  1. Observations: type the temperature, pulse, breathing rate, BP and SpO₂ and click Save. Readings outside the normal range for the patient's age show in red.
  2. Medicines: each medicine prescribed for the admission is listed with the doses given so far. Click Given when you give a dose. If a dose is not given, click Not given, choose withheld or refused, and write the reason. MediCore shows when the next dose is due and asks before a dose is recorded early.
  3. Discharge: the summary is filled in from the record. Complete the condition on discharge, medicines to take home and the follow-up date, then click Discharge, print and send to cashier.

When admitting from a visit, MediCore suggests the ward that suits the patient's age and sex: children to the paediatric ward, newborns to the newborn unit.

  • Bed charges post daily at the ward's rate. Use Post today's bed charges once a day if you need them earlier.
  • Each discharge summary prints with the patient's details, allergies and a signature line for the file and the patient.

19

Websites

For: owners, Pentarch

The built-in facility website

Every branch has a shop-style website inside MediCore at /site, for example http://192.168.1.20:4000/site. Customers on the facility Wi-Fi can browse products with pictures and prices, add to cart, book appointments and see the lab menu. Orders and bookings land straight in MediCore.

The online website (WordPress)

For the public internet, Pentarch builds a WordPress site on the facility's own domain, with real product photos, shop, services, lab prices and WhatsApp ordering. Pentarch installs it; the owner only edits prices and contact details. Orders arrive on the pharmacy's WhatsApp.

Coming with cloud sync

When MediCore's cloud sync is switched on, online orders and bookings will also flow into MediCore automatically, and stock on the website will follow the system.

For: Pentarch staff only

Signing in as the super administrator opens the console: every client and branch on this installation, with patients, collections and stock alerts.

21

Going live checklist

For: owner and Pentarch, on the day the facility starts real use
  • Train staff on the sample data first (one or two days).
  • Settings → Facility details: correct name, phone, email, location, KMHFR code, KRA PIN and partner list.
  • Settings → Data & backup → Remove sample data.
  • Settings → Staff & access: add every real staff member with the right role; deactivate practice accounts.
  • Settings → Service prices and Lab → Test menu: confirm your prices.
  • Pharmacy → Inventory → Import stock: load the shop's stock list from Excel (saved as CSV) with packs, batch and expiry. Use Receive stock for anything left over.
  • Change the Pentarch super PIN on this computer.
  • Reserve the main computer's IP address in the router; bookmark it on every device.
  • Set up the weekly backup (Chapter 13) and do the first one today.

How to back up

  1. Open Settings → Data & backup and click Download backup now. You do not need to stop MediCore.
  2. Copy the file to a flash disk or Google Drive. Keep the last four weekly copies, one of them away from the premises.
  3. If the black window can be closed at the end of the day, a copy of the whole data folder is a second safe backup.
To restore

Use Restore from a backup file in Settings → Data & backup (Chapter 13). For a folder copy: stop MediCore, rename the current data folder to data-old, copy the backup in as data, and start MediCore.

Screens look old, no version number in the menuYou are running an older copy. Update (Chapter 2) and press Ctrl+F5.
“Node.js is not installed”Install Node.js 22 LTS from nodejs.org on the main computer, then run start-medicore.bat again.
Setup did not finishThe first install needs internet. Connect and run start-medicore.bat again.
Forgot PINThe administrator resets it in Settings → Staff & access.
Can't sell an item: “not enough stock”Check the item's batches. Expired batches are not sold. Receive stock or adjust after a count.
Rx item blocked at the counterEnter the prescription reference, or let the pharmacist review it.
“Something went wrong on this screen”Click Reload. Your data is safe. If it repeats, note what you clicked and tell Pentarch support.
A menu is missingYour role does not include it, or the service is switched off in Settings → Type & services.
